# 학습 방법 가이드 — 이 프로젝트로 공부하는 순서

프로젝트 루트에서 순서대로 따라가면 됩니다.

## 1단계. 전체 그림 파악
- `README.md` — 프로젝트 구성과 교안 목록(챕터 1~6, 부록) 훑어보기
- `notes/00_학습계획.md` — 진행 체크리스트 확인 (지금은 챕터 1~6 + 부록 4종 노트 완료, 실습 2개만 남은 상태)

## 2단계. 챕터별 요약 노트로 학습 (순서대로)
`notes/` 폴더에서 아래 순서로 읽는다. 각 노트는 "챕터 개요 → 핵심 요점 → 실습/적용 포인트 → 궁금한 점" 구조이며, 이미지로만 있던 다이어그램·스크린샷도 `[이미지 확인]` 표시로 텍스트화되어 있다.

1. `1_과정소개_환경설정.md`
2. `2_AI트렌드_Top4툴.md`
3. `3_콘텐츠생성_문서제작.md`
4. `4_프롬프트엔지니어링.md`
5. `5_AI활용Workflow실습.md`
6. `6_Gems_자산화.md`

막히거나 원문을 더 보고 싶으면 같은 번호의 `markdown/N_...md`(PDF 전체 텍스트 추출본)를 대조해서 본다.

## 3단계. 부록으로 심화 학습 (선택, 순서 무관)
- `7_부록_딥리서치1_메모리로봇.md`, `9_부록_Perplexity_메모리로봇.md` — 같은 주제를 다른 AI 도구로 조사한 두 리서치를 비교하며 "AI 산출물 교차검증" 감각 익히기
- `8_부록_딥리서치2_AI스마트폰.md` — 챕터3 실습의 완성본 예시
- `10_부록_프롬프트CopyBook.md` — 전체 챕터의 프롬프트 원문 모음 + 재사용 가능한 Web App 구조

## 4단계. 직접 실습 (실제 Gemini 로그인 필요 — 브라우저에서 직접 수행)
- `실행가이드_챕터5_workflow실습.md` — 체크박스 따라가며 목적수립→리서치→선별→슬라이드→웹제안서 5단계 실습. 막히면 `source/workflow_samples/`의 완성 산출물과 비교
- `실행가이드_챕터6_미션7_Gem제작.md` — GeekNews 기반 "AI 트렌드 설명 비서" Gem 제작, URL 공유까지 완료

## 5단계. 진행 상황 기록
- 각 노트를 학습하며 궁금한 점이 풀리거나 실습을 마치면 `notes/00_학습계획.md`의 체크박스를 `[x]`로 갱신한다.

## 예상 소요 시간
- 텍스트 노트 학습(1~3단계): 순서대로 읽는 데 1~2시간
- 실습(4단계): Gemini 응답 대기 시간 포함해 각 30분~1시간
