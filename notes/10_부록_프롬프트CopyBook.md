# 부록 4. 프롬프트 CopyBook — 핵심 요약 노트

> 원본: `source/프롬프트_CopyBook.html` (단일 HTML 앱, 639줄)

## 개요
챕터 2~6에서 실습에 사용된 모든 프롬프트를 **챕터별·Unit별로 정리해 클릭 한 번에 클립보드로 복사**할 수 있게 만든 자체 제작 Web App. 좌측 사이드바에서 챕터(Chapter 2~6)를 선택하면 우측에 Unit별 카드가 나열되고, 카드를 클릭하면 해당 프롬프트 원문이 그대로 복사된다. 순수 HTML/CSS/JS로 만들어졌고 외부 서버 없이 파일 하나로 동작 — 챕터 6에서 배운 "Gem/자산화"의 결과물이자, 스스로가 하나의 완성된 실습 산출물 예시이기도 하다.

## 핵심 요점

### 1. 구조 — 데이터와 렌더링의 분리
- `<script type="text/plain" class="chapter-data" data-label="Chapter N">` 태그 안에 원문 텍스트를 그대로 붙여넣는 방식. `type="text/plain"`이라 브라우저가 실행하지 않고 텍스트로만 보관하며, HTML 이스케이프가 필요 없다.
- 파싱 규칙: `[Unit NN] 제목` 헤더 → `---`로 구분된 본문 → 프롬프트는 빈 줄(`\n\n`) 기준으로 분리. `parseChapter()` 함수가 정규식으로 이를 해석해 Unit·프롬프트 배열로 변환한다.
- 데이터(txt)와 로직(JS)이 완전히 분리되어 있어, 새 챕터의 프롬프트를 추가할 때는 `<script class="chapter-data">` 블록만 하나 더 넣으면 됨 — 유지보수 편의성이 높은 설계.

### 2. 담긴 프롬프트 원문 (챕터별 실습에서 실제 사용된 것)
- **Chapter 2** (Unit 6): 메모리·로봇 트렌드 딥리서치 3단계 프롬프트(조사→조사→결합 인사이트) + 요약 난이도별(2줄/10줄/20줄) 프롬프트 + 할 일 관리 Web App 생성 프롬프트.
- **Chapter 3** (Unit 1): 스마트폰 기획안 초안 → 교차검증 → 피드백 반영 → 이미지 3장 생성 → 발표자료 완성까지 전체 7개 프롬프트.
- **Chapter 4** (Unit 3): HBF 기술 발표자료 실습의 Blindspot Pass → Brainstorming → Prototypes → Interviews → Quizzes 전체 9개 프롬프트 + 4대 기법 정리 프롬프트.
- **Chapter 5**: Unit 1(배경 설명)부터 Unit 5(인터랙티브 웹 제안서)까지 5단계 Workflow의 프롬프트 전체가 원문 그대로 수록.
- **Chapter 6** (Unit 1, 3): 2D 애니메이션 프로필 Gem 프롬프트 + AI 트렌드 설명 비서 Gem 프롬프트.

### 3. UI/UX 설계 포인트
- 카드 클릭 시 `navigator.clipboard.writeText()`로 복사, 실패 시 `document.execCommand("copy")` 폴백까지 구현 — 구형 브라우저 대응.
- 복사 성공 시 카드 테두리가 초록색으로 바뀌고 "복사됨 ✓" 힌트 표시 + 하단 토스트 알림(1.6초 후 자동 소멸) — 클릭했는지 안 했는지 헷갈리지 않게 하는 피드백 설계.
- 모바일 대응: 720px 이하에서는 사이드바가 세로→가로 탭 형태로 전환.

## 실습/적용 포인트
- **프롬프트 라이브러리 패턴**: 반복 사용하는 프롬프트를 카테고리(챕터/Unit)별로 정리하고 원클릭 복사 가능하게 만드는 이 구조는, 실무에서 "회사 표준 프롬프트 모음집"을 만들 때 그대로 재사용 가능한 템플릿이다.
- **데이터/로직 분리 설계**: `<script type="text/plain">` 트릭은 정적 사이트에 텍스트 데이터를 이스케이프 없이 심을 때 유용한 패턴 — Gemini에게 "이런 구조의 Copy Book Web App을 만들어줘"라고 요청할 때 참고 템플릿으로 쓸 수 있다.
- 이 파일 자체가 챕터 6 "Gems를 활용한 자산화"의 정신(개인 프롬프트 노하우를 재사용 가능한 자산으로 만들기)을 코드 형태로 구현한 사례.

## 궁금한 점
- Chapter 1 데이터가 없는데(Chapter 2부터 시작), 챕터 1은 환경설정 위주라 재사용할 프롬프트가 없어서 제외된 것으로 추정된다.
- 이 HTML을 Gemini Gem처럼 URL로 공유하는 방법(정적 호스팅 vs 로컬 파일 실행)이 교안에 명시되어 있지 않아, 팀 공유 시 어떤 배포 방식을 권장하는지 확인이 필요하다.
