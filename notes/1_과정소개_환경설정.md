# Chapter 1. 과정 소개 및 환경 설정 — 핵심 요약

## 챕터 개요
실무자 AI 교육(멀티캠퍼스)의 첫 챕터로, 본격적인 AI Tool 수업 전 교육 플랫폼 AI Studio를 소개하고 Gemini 유료 계정 로그인과 실습 툴 구성을 마치는 환경 설정 단계다. 과정 흐름: Ch.1(과정·툴 소개) → Ch.2~3(AI 트렌드) → Ch.4(시각화 문서 생성) → Ch.5~6(프롬프트 엔지니어링 Workflow 프로젝트). 수업은 Chrome(https://www.google.com/intl/ko_kr/chrome)으로 진행하며, 공용 PC는 캐시·쿠키 삭제, 전체 로그아웃 또는 시크릿 모드로 시작한다.

## 핵심 요점

### Unit 1. AI Studio 플랫폼 안내
- AI Studio(https://aistudio.multicampus.com/ais/sec-ds/login)는 교재 다운로드·과제 제출·보조강사 Q&A를 담당하는 교육 종합 플랫폼. 로그인은 Knox ID와 동일, 초기 비밀번호 `1234` → 첫 로그인 후 8자리 이상으로 변경.
- 출석 후 '실습 시작하기'로 강의실 입장. 캡처는 영역 선택 → Ctrl+C → Ctrl+V로 채팅 붙여넣기. 보조강사는 실습보조(실습 질문)·운영보조(운영 질문)로 구분, 질문은 Zoom이 아닌 AI Studio 채팅으로.
- 공지사항에서 Gemini 유료 계정 ID/Password 확인(메모장에 복사). 과제/평가/설문 메뉴에서 '미션' 확인.

### Unit 2. Gemini 계정 로그인
- AI 갤러리 > 추천 > 'AI 실습계정' 버튼으로 로그인 페이지 이동 후 안내된 유료 계정으로 로그인. "본인 계정이 맞습니까?" 창은 '계속' 클릭.
- 로그인 문제는 메인강사님에게 캡처와 함께 채팅으로 문의. 창이 작으면 모바일 화면으로 동작하므로 창을 키워 진행.

### Unit 3. Gemini 채팅 테스트
- 세 가지 모델: ① Flash — 빠른 응답·딜레이 없는 대화(단점: 의도 파악 약함) ② Thinking Model(사고모델) — 의도를 정확히 파악, **수업 사용 모델**, 유료 버전에서 한도 없음 ③ Pro — 코딩·문제풀이 특화.
- 입력 메시지를 '프롬프트'라 부른다. 우측 상단 메뉴: 임시채팅(이력 남지 않는 비밀대화), 업그레이드 버튼(구독 유도 마케팅 — 무시), 테마(시스템/밝은/어두운, 테스트 후 시스템 테마 유지).

### Unit 4. 그 밖에 실습 도구 안내
- 수업 5개 툴: AI Studio, Gemini(유료, 메인 실습), Google Docs, Google Presentation, Gemini Notebook. ChatGPT·Gemini는 사내 순차 오픈 예정.
- google.com에서 교육용 계정 로그인(본인 인증 '다음' 2~3회 반복 가능) → App > Docs > 빈 문서. 파일 > 다운로드 > .docx 저장 — Gemini 결과물을 문서로 저장할 때 Docs 사용.
- Gemini Notebook은 Gemini > 설정 > Gemini Notebook. 접속 실패 시 브라우저 재시작 → 교육생 계정 전환 → http://notebook.google.com/ 접속.

### 외부 AI 서비스 사용 유의사항 (필독)
- 기밀/민감 정보 유의 → 사내 데이터 사용 금지. 교육 후 업무 적용 시에도 가상 데이터로 컨셉만 생성하고, 실제 데이터는 사람이 직접 업데이트하는 방향으로 사용.

## 실습/적용 포인트
- AI Studio 로그인 → 비밀번호 변경 → 강의실 입장 → 캡처해서 전체 채팅에 화이팅 메시지 남기기.
- 공지사항에서 Gemini 계정 확인 → 유료 로그인('계속' 처리) → 새 대화 열기, 프롬프트("오늘 점심 메뉴 추천해줘") 입력, 대화 이력 이름 변경("점심 추천"), 임시채팅·테마 테스트.
- Google Docs 빈 문서 작성 후 .docx 다운로드, Gemini Notebook 접속 확인.

## 궁금한 점
- AI Studio 로그인 URL이 원문에서 줄바꿈으로 분리되어 있어(sec…ds/login) 하이픈 포함 여부 등 정확한 경로를 접속 시 확인이 필요하다.
- Thinking Model 선택 방법(모델 전환 UI 위치)은 이 챕터에 안내가 없어 다음 챕터에서 확인하고 싶다.
